# Terms of use and licenses

You may read, copy, share and adapt everything on Terminal Email under its open licenses. The information is checked against each project's own sources, but it comes with no warranty.

- share your adapted version under the same license.

The data is free to use in your own tools: [/api/clients.json](/api/clients.json) has every client and tool, and [llms.txt](/llms.txt) lists every page.

## Accuracy

Facts come from each project's website, repository, license file and package listings, and each page links to the sources it was checked against. Programs change, so a fact can go out of date between checks. Check the project's own documentation before you rely on a detail, and [report a mistake](https://github.com/forwardemail/terminalemail.com/issues/new?template=correction.yml) when you find one.

Install commands and configs are given as examples. Read a command before you run it, especially one that pipes a download into a shell.
